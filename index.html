❓ FAQ

Frequently Asked Questions

Everything you need to know about HostClaw.ai

How do I connect my OpenClaw agent to WhatsApp? +
It's simple! After creating your agent in HostClaw, go to the Channels tab and select WhatsApp. You have two options: (1) Use WhatsApp Cloud API for business accounts - just scan a QR code, or (2) Use our WhatsApp Business API integration. Both methods take under 2 minutes to set up and your agent will be live immediately.
How do I connect my OpenClaw agent to Telegram? +
Telegram setup is even easier! Message @BotFather on Telegram, create a new bot, and copy the API token. Paste that token into the Telegram channel settings in your HostClaw dashboard, click Deploy, and your agent is instantly connected. No QR codes or complex configuration needed.
What is OpenClaw and how does HostClaw help? +
OpenClaw is an open-source AI agent framework. HostClaw.ai provides fully managed cloud hosting for OpenClaw agents, eliminating the need to set up and maintain your own servers. We handle deployment, scaling, security, and monitoring so you can focus on building your agent's capabilities.
How does the payment gateway integration work? +
We integrate with Stripe to provide seamless payment processing. You can set up subscriptions, one-time payments, or usage-based billing for your agents. Revenue is deposited directly to your Stripe account. We take a small platform fee only when you make money.
Can I use my own AI model API keys? +
Absolutely! You can bring your own OpenAI, Anthropic, or other API keys. Alternatively, use our bundled credits which offer discounted rates on major AI providers. You have full control over which models your agents use.
Is my data secure? +
Security is our top priority. All data is encrypted at rest and in transit. We use SOC 2 compliant infrastructure, provide automated backups, DDoS protection, and regular security audits. Enterprise plans include additional compliance features like GDPR tools and audit logs.
What happens if I exceed my plan limits? +
We'll notify you when you're approaching limits. You can upgrade anytime, or enable auto-scaling for pay-as-you-go overage charges. We never shut down your agents unexpectedly - your users stay connected.
Can I deploy agents for my clients? +
Yes! Our Enterprise plan includes white-label capabilities perfect for agencies. Deploy branded agents for clients, manage them from a single dashboard, and set custom pricing. We also offer reseller partnerships with volume discounts.
