OpenAI Paid
GPT-4o, GPT-4 Turbo, GPT-3.5
1
Create OpenAI Account
Go to OpenAI's website and sign up for a free account. You'll get $5 in free credits to start.
Sign Up on OpenAI →
2
Go to API Keys Page
Once logged in, navigate to the API keys section in your account settings.
Open API Keys Page →
3
Create New API Key
Click "Create new secret key", give it a name (e.g., "ChatsAI"), and copy the key. It starts with "sk-".
Your key will look like: sk-abc123def456ghi789jkl012mno345pqr678stu901vwx234yz
4
Add to ChatsAI
Go to Settings, paste your key, and select your preferred model (GPT-4o recommended).
Go to Settings →
💡 Pro Tip
New accounts get $5 in free credits. After that, you only pay for what you use (~$0.01-0.03 per message).
🧠
Anthropic (Claude) Paid
Claude 3.5 Sonnet, Claude 3 Opus
1
Create Anthropic Account
Sign up for an Anthropic account. New users get $5 in free credits.
Sign Up on Anthropic →
2
Get API Key
In the console, go to "API Keys" section and click "Create Key". Your key starts with "sk-ant-".
Your key will look like: sk-ant-api03-abc123def456ghi789jkl012mno345pqr678stu901vwx234yz-abc123def
3
Add to ChatsAI
Paste your key in Settings and select Claude 3.5 Sonnet for best results.
Go to Settings →
💡 Why Claude?
Claude excels at long conversations and complex reasoning. Great for detailed discussions and analysis.

NVIDIA FREE
Llama 3.1 Nemotron, Llama 3.1 70B/405B
1
Create NVIDIA Account
Go to NVIDIA's developer site and create a free account. No credit card required!
Go to NVIDIA Build →
2
Select a Model
Browse the available models and click on "Llama 3.1 Nemotron 70B Instruct" (recommended) or any other free model.
3
Get Your API Key
Click "Get API Key" button. The key starts with "nvapi-" and is free to use.
Your key will look like: nvapi-abc123def456ghi789jkl012mno345pqr678stu901vwx234yz
4
Add to ChatsAI
Paste your key in Settings. You get 1,000 free requests per day!
Go to Settings →
🎉 Completely Free!
NVIDIA gives you 1,000 requests per day at no cost. Perfect for testing or light usage. No credit card needed!
⚠️ Rate Limits
Free tier: 1,000 requests/day, 20 requests/minute. If you hit limits, wait a minute or consider upgrading.
❓ Frequently Asked Questions
Which provider should I choose?
Start with NVIDIA (FREE) to test things out. For best quality, use OpenAI GPT-4o or Anthropic Claude 3.5.
Is my API key safe?
Yes! Your API key is encrypted before storage. We never share or expose your keys. You can revoke them anytime from the provider's website.
How much will I pay?
NVIDIA: $0 (1,000 requests/day free)
OpenAI: ~$0.01-0.03 per message
Anthropic: ~$0.01-0.03 per message
You only pay for what you use. Set billing limits in your provider account.
Can I use multiple providers?
Yes! Add keys for all providers in Settings, then select your default. You can switch anytime.
